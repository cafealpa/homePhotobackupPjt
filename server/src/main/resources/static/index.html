대용량 로컬 임포트

하위 폴더까지 전부 훑습니다. 이미 있는 사진은 내용 해시로 걸러져 중복 처리되므로, 중간에 멈추거나 서버가 꺼져도 같은 경로로 다시 시작하면 이어서 진행됩니다.

복사는 사진 용량만큼 디스크를 더 씁니다 (2TB면 합계 4TB). 원본과 저장소가 같은 드라이브라면 이동이 복사 없이 즉시 끝나고 공간도 더 들지 않습니다. 이동해도 중복으로 걸러진 파일은 원본 자리에 그대로 남습니다.

임포트한 사진은 기기별 화면에서 서버 임포트로 묶입니다. 썸네일·얼굴·장면 분석은 임포트가 끝난 뒤에도 백그라운드에서 계속 처리됩니다.
