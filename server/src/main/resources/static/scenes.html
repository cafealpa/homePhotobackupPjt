분석 연결 설정

키 한 줄을 담은 서버 파일을 지정하거나, 비워 두고 GEMINI_API_KEY 환경변수를 사용하세요. 키 값은 이 화면으로 전송되지 않습니다. Gemini는 긴 변 최대 768px로 축소한 사진을 MEDIUM 설정으로 Google에 보내 분석합니다. 로컬 VLM 주소는 메인 설정에서 변경할 수 있어요.

Gemini 장면 분석은 표준 요금의 50%인 배치로 처리해요. 완료 목표 시간은 24시간이며, 결과가 도착하면 반영됩니다. 일시정지는 새 제출과 결과 조회를 멈추며, 이미 제출한 배치는 Google에서 계속 처리돼요. 다시 시작하면 결과를 가져옵니다. 문서 OCR은 기존 실시간 방식입니다.

인물을 선택하고 장면을 검색하세요. 선택한 인물이 나온 사진을 찾으며, 그 인물이 행동의 주체인지는 구분하지 않아요.
