# HomePhoto Server 0.1.12

## 변경 사항

- Gemini 장면 분석을 실시간 호출에서 Batch API로 전환했습니다. 기존 `GEMINI` 설정도 업데이트 후 배치 경로를 사용합니다. 로컬 VLM과 문서 OCR은 기존 실시간 방식을 유지합니다.
- 최대 20장, 약 18MB 이내로 묶어 제출하고 최대 100개 배치를 대기시킵니다. 원격 작업은 60초 간격으로 조회하며 서버 재시작 후에도 이어서 조회합니다.
- 결과를 사진별 키로 매칭하고 성공한 사진의 설명·태그·문서 판별을 저장합니다. 부분 실패, 삭제된 사진, 결과 저장 실패 후 재조회에 대응합니다.
- 접수 여부가 불명확한 요청은 중복 과금을 막기 위해 자동 재제출하지 않습니다. Google AI Studio에서 배치 접수 여부를 확인한 후 화면에서 실패 항목을 재등록할 수 있습니다.
- 장면 분석 화면에 배치 대기 수와 일시정지 동작을 표시합니다.

## 사용과 호환성

- [Google 공식 안내](https://ai.google.dev/gemini-api/docs/batch-api) 기준 배치 요금은 표준 요금의 50%이며 완료 목표 시간은 24시간입니다. 실제 완료 시간은 서비스 상태에 따라 달라집니다. 실시간 API로 자동 우회하지 않습니다.
- 일시정지는 새 제출과 결과 조회를 멈춥니다. 이미 제출된 배치는 Google에서 계속 실행되어 과금될 수 있습니다. 분석을 다시 시작하면 결과를 가져옵니다.
- 마이그레이션 9가 배치 상태 테이블 두 개를 추가합니다. 기존 사진·분석 결과·설정은 유지하며 성공한 사진을 일괄 재분석하지 않습니다.
- Windows x64 / Java 21 기준입니다. ZIP의 서버 JAR와 해시 이름의 얼굴 런타임 JAR를 같은 폴더에 두세요. 런타임 파일명을 변경하지 마세요.
- 모델·ffmpeg·운영 설정·API 키·사진 데이터는 패키지에 포함하지 않습니다.

## 검증 범위

- 서버 전체 295개 테스트와 웹 스크립트 10개 테스트를 통과했습니다. 실패·오류·건너뜀은 없습니다. 배치 전용 회귀 테스트는 재시작 복구, 키 기반 결과 매칭, 부분 실패, 할당량 거절, 불명확한 제출의 자동 재시도 방지, 조회 장애, 삭제 사진 제외, DB 트랜잭션 롤백을 검증합니다.
- 운영 데이터와 분리한 Java 21 임시 설치에서 ZIP 기동, 건강 상태, 배치 상태 API, 새 장면 분석 화면, 정상 종료를 확인했습니다. 재시작·업데이트 가능 상태도 true였습니다. 실제 운영 서버의 업데이트 버튼 실행 검증은 아닙니다.
- 실제 Gemini 유료 API의 처리 시간·응답 품질·청구 금액과 운영 서버 교체는 별도 확인 대상입니다.

## 설치와 롤백

업데이트 전 서버를 정상 종료하고 DB·설정·기존 JAR 쌍을 백업하세요.
이전 버전은 원격 배치 상태를 이해하지 못하므로 제출된 배치가 남아 있는 상태에서 장면 분석을 켜고 구버전으로 되돌리면 중복 호출이 발생할 수 있습니다.
가능하면 배치 결과를 모두 반영한 뒤 롤백하세요. 긴급 롤백은 장면 분석을 끈 설정으로 서버를 종료하고 이전 JAR 쌍을 복원한 뒤, Google의 남은 작업을 확인하기 전까지 분석을 켜지 마세요.
DB 백업 복원은 업데이트 이후 데이터가 사라질 수 있으므로 현재 DB를 먼저 별도로 보관하세요.
GitHub 릴리즈 공개는 운영 서버의 파일 교체나 재시작을 자동 수행하지 않습니다.
