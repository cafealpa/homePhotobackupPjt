# v0.1.6-rc4

## 주요 변경

- 원본 저장소 연결이 끊겨도 서버 수신 큐에 백업을 보관하고 연결 복구 후 자동으로 배치합니다.
- 디스크 여유 공간과 수신 큐 용량을 검사하고 병렬 업로드 공간을 예약해 디스크 고갈을 방지합니다.
- 웹 설정에서 안전한 서버 종료와 GitHub 릴리스 확인·업데이트를 지원합니다.
- 얼굴 인식을 JVM ONNX/OpenCV로 전환하고 완료된 사진부터 인물 화면에 표시합니다.
- Gemini 장면 분석, 실시간 결과 화면과 재시도를 지원합니다. 분석 이미지는 긴 변 최대 768px JPEG로 변환하고 MEDIUM 해상도로 요청합니다.
- Google Photos 게시 큐, 동영상 재개 업로드, 기존 파일명 제외와 일괄 게시를 지원합니다.
- 주간 가족 앨범과 함께 찍은 하루 기능을 추가합니다.

## 업데이트 전 확인

- Windows x64와 Java 21 이상이 필요합니다. 서버를 종료하고 DB를 백업한 뒤 업데이트하세요.
- **첫 실행 시 마이그레이션으로 기존 얼굴 결과와 인물 이름을 한 번 삭제하고 전체 사진의 얼굴 인식을 다시 예약합니다.** 원본 사진은 삭제하지 않습니다.
- 얼굴 모델 `det_10g.onnx`, `w600k_r50.onnx`는 포함하지 않습니다. 기존 `models/buffalo_l` 또는 설정한 모델 경로를 유지하세요.
- Gemini는 서버 API 키 및 공급자 설정이 필요합니다. 이번 릴리스 검증에서 유료 API 호출은 실행하지 않았습니다.
- 설정·DB·사진·개인 OAuth 정보·모델과 ffmpeg는 패키지에 포함하지 않습니다. 기존 설치의 해당 파일은 유지하세요.
- 서버와 Windows x64 얼굴 인식 런타임을 JAR 두 개로 분리했습니다. 각각 GitHub Git의 100MB 제한 미만이며 `deploy/`와 Release 첨부파일로 제공합니다.
- 기존 설치: 최신 `update-server-jar.ps1`로 갱신하거나 서버 종료 후 **두 JAR를 같은 설치 폴더에** 복사합니다. 런타임 파일명은 변경하지 마세요. 신규 설치: ZIP을 풀고 필요한 모델과 ffmpeg를 별도로 준비합니다.
- 단일 JAR만 지원하는 이전 업데이트 도우미를 쓰고 있다면 이번 버전은 스크립트 또는 수동 복사로 설치하세요. 이번 버전부터 웹 업데이트도 런타임을 함께 검증·설치합니다.
- 이전 버전으로 되돌릴 때는 서버를 중지하고 이전 JAR와 업데이트 전 DB 백업을 함께 복구하세요.

## 검증

- 전체 서버 테스트 194개 통과(실패·오류·건너뛴 테스트 없음). 런타임 누락·변조·교체 검증 포함.
- ZIP을 풀어 분리 JAR로 서버 기동 및 health HTTP 200 확인. 분리 런타임으로 OpenCV와 ONNX 얼굴 검출 모델 로드 확인.
- 실행 JAR 빌드 완료. SHA256SUMS.txt로 첨부파일 무결성을 확인할 수 있습니다.
- 실제 운영 서버의 설치·재시작은 이번 GitHub 배포에 포함하지 않습니다.
