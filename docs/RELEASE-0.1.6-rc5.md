# v0.1.6-rc5

## 주요 변경

- 장면 검색에 JVM 한국어 설명 임베딩 검색을 추가했습니다. 기존 설명·태그로 로컬 색인을 만들며 사진 재분석이나 Gemini 호출 없이 단어 검색과 의미 검색을 결합합니다.
- 공백으로 나눈 검색 단어를 설명·태그·파일명에서 찾고, 단어·의미 양쪽 일치 → 단어만 일치 → 의미만 일치 순으로 표시합니다. 의미 후보는 최대 200개이며 결과는 페이지당 40개입니다.
- 대시보드 상단에서 백업·분석 진행 상황과 오류 요약을 확인하고 자동 갱신합니다. 설정 버튼과 안전 종료 버튼의 표시를 개선했습니다.
- RC를 포함한 전체 릴리스 목록과 업데이트 테이블 표시를 개선했습니다.
- 모델 준비 스크립트와 운영 배포·롤백 가이드를 추가했습니다.

## 설치와 업데이트

- Windows x64와 Java 21 기준입니다. 서버를 정상 종료하고 실제 DB·설정·키·기존 JAR를 백업한 뒤 운영자가 교체·재시작하세요. 이 릴리스 게시가 운영 서버를 자동 재시작하지는 않습니다.
- 기존 형식대로 서버 JAR와 해시 이름의 Windows 런타임 JAR를 같은 폴더에 두세요. 런타임 이름을 바꾸지 마세요. ZIP에도 두 JAR와 체크섬이 들어 있습니다.
- 설명 검색 모델은 포함하지 않습니다. 저장소의 `prepare-caption-model.ps1`로 약 129.1MiB의 고정 모델을 준비하거나 검증된 모델 세 파일을 복사하세요. 모델은 MIT 라이선스이며 서버 시작 시 자동 다운로드하지 않습니다.
- 모델 기본 위치는 실행 작업 폴더 기준 `models/caption-e5`입니다. `homephoto.caption-search.model-dir`로 절대경로를 지정할 수 있습니다. 인덱스 기본 위치는 `storage-root/caption-search/<model-id>`이며 `homephoto.caption-search.index-dir`로 인덱스 루트를 바꿀 수 있습니다.
- 시작 약 15초 뒤 기존 설명을 자동 색인합니다. 장면 분석 화면에서 로컬 JVM 상태와 인덱스 수를 확인하세요. 모델이 없거나 초기화에 실패해도 단어 검색은 동작하며 약 60초 후 재시도합니다.
- 설정·DB·사진·개인 키·OAuth 정보·인덱스·모델·ffmpeg는 배포 자산에 포함하지 않습니다. 기존 파일을 유지하세요. 기존 얼굴 모델도 별도로 유지해야 합니다.
- Python 이미지 의미 검색과 얼굴 유사검색 경로는 제거하지 않았습니다. 이번 JVM 설명 검색에는 Python 실행이 필요하지 않습니다.

## DB와 롤백 주의

- 설명 검색 초기화 시 `caption_search_changes` 큐 테이블과 트리거 5개를 추가합니다. 기존 설명을 파괴적으로 변경하지 않지만 이전 JAR 복원이나 기능 비활성화 후에도 객체가 남으며 자동 역마이그레이션은 없습니다. 큐 테이블만 삭제하지 마세요.
- 정확한 배포 전 상태로 돌아가려면 서버를 중지하고 이전 JAR·런타임·설정과 일관된 DB 백업을 복구해야 합니다. 복원 시점 이후 데이터 손실에 유의하고 인덱스도 DB와 맞추거나 빈 별도 경로에서 재색인하세요.
- **rc4 이전 버전에서 올라오는 경우 rc4의 얼굴 엔진 마이그레이션도 적용됩니다. 기존 얼굴 결과와 인물 이름을 한 번 삭제하고 얼굴 인식을 다시 예약하는 변경이므로 rc4 릴리스 노트를 먼저 확인하세요.** rc4 적용을 완료한 DB에는 이번 릴리스가 그 마이그레이션을 새로 추가하지 않습니다.
- 의미 검색만 중단하려면 `homephoto.caption-search.enabled=false`를 적용하고 운영 절차대로 재시작할 수 있습니다.

## 검증과 한계

- 전체 서버 테스트 209개와 대시보드 Node 테스트 3개가 모두 통과했습니다(실패·오류·건너뜀 없음). 공식 스크립트로 배포 JAR/ZIP을 빌드하고 버전·런타임 참조·패키지 내용·체크섬을 검증했습니다. 저장소에 GitHub Actions 워크플로가 없어 원격 CI 실행은 없습니다.
- 개발 PC에서 실제 로컬 모델로 기존 설명 55장 색인과 의미 검색을 확인했습니다. 유료 API 호출·운영 서버 교체·재시작은 릴리스 준비에 포함하지 않습니다.
- 20~30만 장 성능은 실측하지 않았습니다. 기본 유사도 0.80 및 최고점과 차이 0.06은 초기 휴리스틱이며 실제 검색어의 오탐·누락과 초기 색인 부하를 확인해야 합니다.
