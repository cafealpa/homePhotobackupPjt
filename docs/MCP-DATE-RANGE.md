# MCP 촬영 기간 검색

`search_photos`는 기존 하루 검색과 시작일·종료일을 지정하는 기간 검색을 제공한다.

```json
{"date":"2026-09-14","limit":12}
```

```json
{"start_date":"2026-09-01","end_date":"2026-09-30","limit":12}
```

- 날짜는 연도를 포함한 `YYYY-MM-DD`이며 시작일과 종료일을 모두 포함한다.
- `date`와 기간 인자는 혼용하지 않는다. 기간은 양쪽 날짜가 모두 필요하다.
- 연도를 대화에서 알 수 없으면 사용자에게 확인한다. 월 검색은 첫날부터 마지막 날까지 지정한다.
- DB에 저장된 촬영일 기준으로 검색하며 시간대 변환이나 업로드일 검색은 수행하지 않는다.
- 최신 촬영일·ID 순으로 반환한다. 후속 호출은 동일한 날짜 조건과 응답의 `nextCursor`를 사용한다.
- 응답의 `start_date`, `end_date`는 실제 검색 범위다. 기존 하루 검색은 `date`도 유지한다.
- 갤러리는 기간을 표시하고 ‘더 보기’에 같은 조건을 전달한다.
- 검색 결과의 사진 수는 현재 페이지의 장수다. 전체 개수는 아래 집계 도구를 사용한다. 인물·음식 검색은 지원하지 않는다.
- 기존 OAuth 및 미리보기 접근 제어를 그대로 사용한다. 개발 검증은 운영 배포나 실제 ChatGPT 연동 검증을 대신하지 않는다.

## 전체 사진 수 집계

MCP `count_photos`는 위와 동일한 `date` 또는 `start_date` + `end_date`를 받는다.
페이지 인자(`limit`, `cursor`)나 지원하지 않는 조건은 거부한다. 결과에는
`count`(64비트 정수), `date`, `start_date`, `end_date`, `media_type: "PHOTO"`가 포함된다.
갤러리나 미리보기는 생성하지 않는다. 월 검색은 연도를 확인하고 월 첫날과 마지막 날을 지정한다.

서버 API도 같은 날짜 검증 및 DB 필터를 사용한다.

```http
GET /api/v1/photos/count?date=2026-09-01
X-Api-Key: <기존 API 키>
```

```http
GET /api/v1/photos/count?start_date=2026-09-01&end_date=2026-09-30
X-Api-Key: <기존 API 키>
```

기존 웹 로그인 쿠키도 사용할 수 있다. MCP는 OAuth `photos:read`, API는 기존 API 인증을
사용하며 서로의 인증을 대체하지 않는다. 무인증/잘못된 API 키는 401, 누락·혼용·잘못된 날짜는
400을 반환한다. 결과가 없으면 200과 `count: 0`을 반환한다.

집계는 촬영일의 양끝 날짜를 포함하는 DB COUNT이며 페이지 크기와 무관하다.
휴지통·영구 삭제·동영상·키즈노트 전용 사진을 제외한다. 검색과 집계 사이에 사진이 추가되거나
삭제되면 결과가 달라질 수 있다. 운영 배포와 실제 ChatGPT 검증은 별도로 필요하다.
