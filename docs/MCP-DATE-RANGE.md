# MCP 촬영 기간 검색

`search_photos`는 기존 하루 검색과 시작일·종료일을 지정하는 기간 검색을 제공한다.

```json
{"date":"2026-09-14","limit":12}
```

```json
{"start_date":"2026-09-01","end_date":"2026-09-30","limit":12}
```

- 날짜는 연도를 포함한 `YYYY-MM-DD`이며 시작일과 종료일을 모두 포함한다.
- `date`와 기간 인자는 혼용하지 않는다. 기간은 양쪽 날짜가 모두 필요하다.
- 연도를 대화에서 알 수 없으면 사용자에게 확인한다. 월 검색은 첫날부터 마지막 날까지 지정한다.
- DB에 저장된 촬영일 기준으로 검색하며 시간대 변환이나 업로드일 검색은 수행하지 않는다.
- 최신 촬영일·ID 순으로 반환한다. 후속 호출은 동일한 날짜 조건과 응답의 `nextCursor`를 사용한다.
- 응답의 `start_date`, `end_date`는 실제 검색 범위다. 기존 하루 검색은 `date`도 유지한다.
- 갤러리는 기간을 표시하고 ‘더 보기’에 같은 조건을 전달한다.
- 반환된 사진 수는 현재 페이지의 장수다. 전체 개수 집계, 인물·음식 검색은 이번 변경에 포함하지 않는다.
- 기존 OAuth 및 미리보기 접근 제어를 그대로 사용한다. 개발 검증은 운영 배포나 실제 ChatGPT 연동 검증을 대신하지 않는다.
