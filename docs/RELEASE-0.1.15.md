# HomePhoto Server 0.1.15

## 변경 사항

- 장면 분석 화면에서 설명·태그 의미 검색과 이미지 벡터 검색을 통합합니다. 설명이 없는 사진도 이미지 인덱스가 준비되면 검색할 수 있고, 인물 선택은 양쪽 검색에 적용됩니다. 사용할 수 없는 검색 방식은 제외하고 나머지 방식과 단어 검색으로 동작합니다.
- 설정 화면에서 사진·얼굴 검색 모델과 장면·문서 검색 모델의 경로·누락 파일을 확인하고 다운로드할 수 있습니다. 고정 SHA-256 검증을 통과한 파일만 설치하며 기존 정상 파일은 재사용합니다.
- 설정 화면을 기능별 분류 메뉴로 정리했습니다.

## 설치와 롤백

- Windows x64 / Java 21 기준입니다. 서버 JAR와 해시 이름의 얼굴 런타임 JAR를 같은 폴더에 두고 기존 사진·DB·설정·모델을 보존하세요. 업데이트 전 서버를 정상 종료하고 DB·설정·기존 JAR 쌍을 백업하세요.
- 0.1.14 대비 추가 DB 마이그레이션이나 벡터 형식 변경은 없습니다. 통합 검색 연결을 위한 별도 재인덱싱은 필요하지 않습니다. 0.1.13 이하에서 업데이트한다면 0.1.14의 마이그레이션 10 및 초기 장면 재인덱싱 안내를 함께 확인하세요.
- 이미지 검색을 활용하려면 사진·얼굴 벡터 검색을 켜고 모델 준비와 인덱싱을 완료하세요. 통합 검색의 오탐·순위·응답 속도는 운영 사진으로 평가가 필요합니다.
- 모델 다운로드는 버튼을 눌렀을 때 서버가 Hugging Face에 접속해 수행합니다. 사진 모델은 약 1.5GB, 장면·문서 모델은 약 129MiB이며 모델 폴더 쓰기 권한과 여유 공간이 필요합니다. 모델·사진·비밀 설정은 릴리즈 ZIP에 포함하지 않습니다.
- 0.1.14로 롤백할 때는 서버를 정상 종료하고 이전 JAR 쌍을 복원하세요. DB 복원이 필요하면 업데이트 전 백업을 사용하세요.
- GitHub 릴리즈 공개는 운영 서버의 파일 교체나 재시작을 자동 수행하지 않습니다.

## 검증

- 공식 패키징 스크립트로 서버 테스트 318개와 실행 JAR 빌드를 통과했습니다. 실패·오류·건너뜀은 0건입니다. 웹 회귀 테스트 10개도 통과했습니다.
- 릴리즈 ZIP을 임시 폴더에 설치하여 실행 버전 0.1.15, 기본 API, 통합 검색 화면, 모델 2종 상태 API, 설정 메뉴 6개, 업데이트·재시작 가능 상태 및 정상 종료를 확인했습니다.
- 실제 모델 다운로드는 이번 릴리즈 검증에서 수행하지 않았습니다. 설치 로직은 자동화 테스트로 확인했으며 운영 환경에서의 다운로드·검색 품질 검증은 별도입니다.
