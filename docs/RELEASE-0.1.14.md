# HomePhoto Server 0.1.14

## 변경 사항

- 등장인물 이름과 저장된 장면 설명·태그를 결합해 의미 검색 인덱스를 구성합니다. 인물 이름 변경, 얼굴 그룹 연결·이동·숨김·삭제도 증분 반영합니다.
- 설정 화면에서 사진·얼굴 벡터 검색 사용 여부를 저장하면 재시작 없이 적용됩니다. 문서·장면 검색 인덱싱은 별도로 제어합니다.
- 얼굴 그룹화와 장면 분석이 동시에 SQLite에 쓸 때 발생하던 스냅샷 잠금 충돌을 수정했습니다.

## 업데이트와 롤백

- Windows x64 / Java 21 기준입니다. 서버 JAR와 해시 이름의 얼굴 런타임 JAR를 같은 폴더에 두세요. 기존 사진·DB·설정·모델을 보존하세요.
- 업데이트 전에 서버를 정상 종료하고 DB·설정·기존 JAR 쌍을 백업하세요. DB 마이그레이션 10에서 장면 검색 변경 큐·상태·트리거와 인물 조회 인덱스를 준비합니다.
- 기존 장면 설명은 자동 재인덱싱 대기열에 등록됩니다. 이 전환은 저장된 설명과 인물 연결을 사용하며 Gemini 재분석을 요청하지 않습니다. 다른 분석 워커는 기존 설정을 따릅니다.
- 초기 재인덱싱 중에는 의미 검색 결과가 줄어들 수 있습니다. 문서·장면 검색 인덱싱을 시작하고 대기열·처리 중 0건 및 오류 없음으로 완료를 확인하세요. 기존 OCR 인덱스는 유지됩니다.
- 여러 사람이 등장하는 사진에서 행동 주체를 구분하지 않으며, 이름 결합만으로 정확한 인물 필터링을 보장하지 않습니다. 실제 검색 품질은 운영 사진으로 확인이 필요합니다.
- 롤백은 서버를 정상 종료한 뒤 업데이트 전 백업 DB·설정과 0.1.13 JAR 쌍을 함께 복원하세요. 0.1.13에서는 얼굴 그룹화 저장 경합이 다시 나타날 수 있습니다.

## 검증

- 공식 패키징 스크립트로 서버 테스트 307개와 실행 JAR 빌드를 통과했습니다. 웹 회귀 테스트 10개도 통과했습니다.
- 릴리즈 ZIP의 임시 설치에서 기본 API, 장면 검색 화면, 업데이트·재시작 가능 상태와 정상 종료를 확인했습니다.
- GitHub 릴리즈 공개는 운영 서버의 파일 교체나 재시작을 자동 수행하지 않습니다. 실제 운영 DB에서의 마이그레이션·검색 품질 검증은 별도입니다.
