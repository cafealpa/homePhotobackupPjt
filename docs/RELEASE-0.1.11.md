# HomePhoto Server 0.1.11

## 변경 사항

- 장면 분석 화면에서 인물을 선택하고 장면 설명을 함께 검색할 수 있습니다. 기존 이름 지정 인물과 이름 없는 얼굴 그룹을 사용합니다.
- 선택 인물의 사진을 먼저 벡터 검색 대상으로 제한하여 전체 상위 200장 밖의 인물 사진도 후보가 될 수 있습니다. 단어 검색과 페이지 처리에도 같은 인물 조건을 적용합니다.
- 숨긴 얼굴·삭제 사진을 제외하고, 얼굴 그룹 수정은 다음 조회에 반영합니다. 의미 검색을 사용할 수 없으면 인물 조건을 유지한 단어 검색으로 동작합니다.
- 장면분석 프롬프트를 관찰 가능한 행동·사물·색상·배치 중심으로 개선했습니다. 근거 없는 감정·직업·관계 추측과 일반적인 태그를 줄이도록 유도합니다.

## 사용과 호환성

- 장면분석과 얼굴인식은 어느 순서로 실행해도 됩니다. 기존 썸네일 준비 조건을 유지하며, 두 분석 결과와 장면 검색 인덱스가 준비되면 결합 검색에 사용할 수 있습니다.
- 인물 이름을 검색어에서 자동 추출하거나 행동의 주체를 판별하지 않습니다. 인물 선택 후 장면 검색어를 입력하세요.
- 인물 결합을 위한 추가 Gemini 호출·장면 재분석·벡터 재생성은 필요 없습니다. 새 프롬프트는 이후 분석에 적용되며 기존 설명은 자동 변경하지 않습니다.
- DB 마이그레이션과 얼굴 결과 초기화는 없습니다. 사진·DB·설정·모델은 유지하세요.
- Windows x64 / Java 21 기준입니다. ZIP의 서버 JAR와 해시 이름의 얼굴 런타임 JAR를 같은 폴더에 두세요.
- 이전 버전에서 재시작/업데이트 적용 버튼이 실행 명령 조회 문제로 비활성화된다면 서버를 정상 종료하고 JAR를 수동 교체한 뒤 실행하세요. 0.1.10부터 실행 인수 누락 시 단일 JAR 실행 정보를 복원합니다.

## 검증 범위

- 서버 전체 테스트 289개와 웹 스크립트 테스트 10개가 통과했습니다. 실패·오류·건너뜀은 없습니다.
- 운영 데이터와 분리한 Java 21 임시 설치에서 0.1.11 기동, 인물 필터 API, 인물 선택 UI 포함, 정상 종료를 확인했습니다. 재시작·업데이트 가능 상태 모두 true였습니다. 실제 업데이트 교체/재시작 버튼 실행을 운영 서버에서 검증한 것은 아닙니다.
- 인물 사전 필터, 빈 검색어·빈 인물 그룹, 얼굴 숨김·소속 변경, 검색 캐시 분리, 페이지 처리와 의미 검색 불가 시 단어 검색을 회귀 검증합니다.
- 실제 사진의 검색 정확도와 프롬프트 응답 품질, 운영 서버 교체는 별도 확인 대상입니다.

## 설치와 롤백

업데이트 전 서버를 정상 종료하고 DB·설정·기존 JAR 쌍을 백업하세요. 문제가 있으면 서버를 종료한 뒤 이전 JAR 쌍으로 복원하세요.
이 릴리즈의 공개는 운영 서버를 자동 교체하거나 재시작하지 않습니다.
