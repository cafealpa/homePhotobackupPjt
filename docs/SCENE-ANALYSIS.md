# Gemini 장면 분석

웹 뷰어 왼쪽 **장면 분석**(`/scenes.html`)에서 연결 설정, 시작·일시정지, 진행 상황과 결과를 확인한다.

## 시작하기

1. 서버에서 읽을 수 있는 파일에 Gemini API 키만 한 줄로 저장한다. 예: `D:/secrets/gemini-key.txt`. 사진 저장소·웹 공개 폴더·Git 저장소 밖에 두고 서버 실행 계정에 읽기 권한을 부여한다.
2. 장면 분석 화면의 **분석 연결 설정**에서 제공자를 **Google Gemini API**로 선택하고 키 파일의 전체 경로와 사용 가능한 모델 ID를 저장한다. 기본 모델은 `gemini-2.5-flash`이며 계정에서 사용 가능한 모델로 변경할 수 있다.
3. **분석 시작**을 누른다. 이미 큐에 있는 사진부터 처리한다. 누락된 예전 사진은 **미분석 사진 큐에 넣기**로 등록한다. 실행 중이면 등록 직후 처리되므로 소량 시험은 기존 큐 규모를 확인하고 진행한다.

키 파일 대신 서버 프로세스의 `GEMINI_API_KEY` 환경변수도 지원한다. 파일 경로를 지정하면 파일을 우선하며, 환경변수 변경은 서버 재시작 후 적용한다. 키 자체는 설정 API나 결과 화면으로 반환하지 않는다. 기존 로컬 VLM 연결은 `LOCAL` 제공자로 유지되며 자동으로 Gemini로 전환하거나 분석을 활성화하지 않는다.

설정은 기존 방식으로 `config/application.yml`에 저장되며 재시작 후 유지된다. 기존 클라이언트가 새 항목을 생략해도 Gemini 설정은 유지된다.

```yaml
homephoto:
  caption:
    enabled: true
    provider: GEMINI
    gemini-model: gemini-2.5-flash
    gemini-api-key-file: D:/secrets/gemini-key.txt
    timeout-seconds: 180
```

## 저장·재시도 정책

- 활성 사진만 분석한다. 동영상·휴지통·영구 삭제 항목은 제외한다.
- 기존 뷰어용 1600px 썸네일은 유지한다. 분석 요청 직전에 메모리에서 긴 변 최대 768px JPEG(품질 85%)로 축소해 전송한다. 비율을 유지하고 작은 사진은 확대하지 않으며 별도 분석 파일을 디스크에 저장하지 않는다. 로컬 VLM에도 같은 축소본을 보낸다.
- Gemini `generateContent`에 `generationConfig.mediaResolution=MEDIA_RESOLUTION_MEDIUM`을 명시한다. 모델별 이미지 토큰 수는 다르며, API 사용량은 설정된 Google 프로젝트에 발생한다.
- 한국어 설명·태그를 JSON으로 받아 기존 `captions` 테이블에 모델·분석 시각과 함께 저장한다. DB 스키마 변경이나 기존 결과 삭제는 없다.
- **사진 한 장 완료마다** 결과 저장과 작업 완료를 같은 트랜잭션으로 커밋한다. 화면은 3초마다 조회하므로 전체 큐 완료를 기다리지 않는다. 응답 토큰 스트리밍이 아니라 사진 단위 반영이다.
- 전용 단일 워커에서 처리하여 긴 외부 API 호출이 다른 예약 작업을 막지 않는다. 일시정지는 현재 사진을 끝낸 후 적용한다.
- 연결 실패, 키·모델 오류, 할당량 제한, 서버 장애는 시도 횟수를 소모하지 않고 대기한다. 기본 60초, 숫자 `Retry-After`는 60초~24시간 범위에서 반영한다. 설정 변경 후에도 기존 대기 시간이 끝나면 재개한다.
- 개별 사진 분석 실패(차단·잘못된 분석 응답 등)는 3회 후 실패 상태로 표시한다. **실패한 사진 재시도**로 다시 등록할 수 있다. **미분석 사진 큐에 넣기**도 결과가 없는 실패 작업을 재등록한다. 실행 중·대기 중 작업은 중복 등록하지 않는다.
- 기존 성공 결과는 일괄 재분석하지 않는다. 기존 서버 정책대로 재시작 시 RUNNING/FAILED 작업은 PENDING으로 복구된다.

결과 화면은 기존 서버 API 키 로그인을 사용한다. 설명·태그·파일명으로 검색하고 결과/대기/실패/미분석을 페이지당 40장씩 볼 수 있다. 실패 메시지와 다음 연결 재시도 시각도 표시한다.

참고: [Gemini 이미지 이해](https://ai.google.dev/gemini-api/docs/image-understanding), [구조화된 출력](https://ai.google.dev/gemini-api/docs/structured-output).
