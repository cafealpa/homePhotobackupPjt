# HomePhoto Server 0.1.16

## 변경 사항

- 인물 화면에서 지정한 사진 장수 이하의 인물을 한 번에 해제할 수 있습니다. 사진 장수는 중복 없는 사진 수로 계산하며 사진 원본은 삭제하지 않습니다. 대상 얼굴은 숨김 처리됩니다.
- 인물 상세의 오른쪽 패널에서 이름이나 인물 번호로 대상을 검색하고 선택한 인물로 합칠 수 있습니다.
- 대량 인물 합치기의 조회 범위와 불필요한 갱신을 줄이고, 얼굴 워커와 동시에 쓸 때의 SQLite 스냅샷 잠금 충돌을 방지했습니다.
- 큰 화면에서 설정 분류 메뉴와 본문의 폭을 넓혔습니다.

## 설치와 롤백

- Windows x64 / Java 21 기준입니다. 서버 JAR와 해시 이름의 얼굴 런타임 JAR를 같은 폴더에 두세요. 업데이트 전에 서버를 정상 종료하고 DB·설정·기존 JAR 쌍을 백업하세요. 기존 사진·모델을 보존하세요.
- 0.1.15 대비 추가 DB 마이그레이션은 없습니다. 0.1.13 이하에서 업데이트한다면 0.1.14의 마이그레이션 10 및 초기 장면 재인덱싱 안내를 함께 확인하세요.
- 인물 일괄 해제·합치기는 저장된 얼굴 연결과 숨김 상태를 변경합니다. 이전 JAR로 되돌리는 것만으로 작업 결과가 취소되지는 않으므로 대량 작업 전 DB를 백업하세요.
- 0.1.15로 롤백할 때는 서버를 정상 종료하고 이전 JAR 쌍을 복원하세요. 데이터 복원이 필요하면 백업 시점 이후의 변경 손실을 고려해 업데이트 전 DB 백업을 사용하세요.
- GitHub 릴리즈 공개는 운영 서버의 파일 교체나 재시작을 자동 수행하지 않습니다.

## 검증

- 공식 패키징 스크립트로 서버 테스트 320개와 실행 JAR 빌드를 통과했습니다. 실패·오류·건너뜀은 0건입니다. 웹 회귀 테스트 14개도 통과했습니다.
- 릴리즈 ZIP을 임시 폴더에 설치하여 실행 버전 0.1.16, 기본 API, 인물 관리 UI, 빈 테스트 DB의 일괄 해제 API, 모델 상태 API, 설정 메뉴와 정상 종료를 확인했습니다.
- 운영 DB의 대량 인물 작업과 실제 화면 조작 검증은 별도입니다. 운영 서버는 교체하거나 재시작하지 않았습니다.
