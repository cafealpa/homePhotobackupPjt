# HomePhoto Server 0.1.13

## 수정 사항

- Gemini 배치 결과 저장 중 다른 워커가 SQLite에 쓰면 발생하던 `SQLITE_BUSY_SNAPSHOT (database is locked)` 충돌을 수정했습니다.
- 결과 저장과 실패 확정 트랜잭션은 조회 전에 쓰기 잠금을 확보합니다. 응답 JSON 검증은 트랜잭션 밖에서 수행해 잠금 시간을 줄였습니다.
- 기존 원격 배치 ID와 결과 저장의 원자성을 유지합니다. 저장 대기 중인 사진을 다시 등록하거나 Gemini에 배치를 재제출할 필요가 없습니다. 업데이트 후 장면 분석을 켜면 기존 배치 결과 조회와 저장을 이어갑니다.

## 검증 범위

- 수정 직후 실제 SQLite WAL 두 연결로 충돌을 재현하고, 수정 후 동시 쓰기 회귀 테스트를 포함한 서버 전체 297개 테스트가 통과했습니다.
- 사용자 요청에 따라 이번 릴리즈 단계에서는 테스트를 다시 실행하지 않았으며 별도 기동 테스트도 생략했습니다. 빌드·패키징과 업로드 파일 체크섬 확인만 수행합니다.
- 실제 운영 환경에서의 수정 효과는 업데이트 후 확인이 필요합니다.

## 설치와 롤백

- Windows x64 / Java 21 기준입니다. 서버 JAR와 해시 이름의 얼굴 런타임 JAR를 같은 폴더에 두세요. 기존 DB·사진·설정·모델을 보존하세요.
- 0.1.12 대비 추가 DB 마이그레이션은 없습니다. 업데이트 전 서버를 정상 종료하고 DB·설정·기존 JAR 쌍을 백업하세요.
- 0.1.12로 롤백하면 기존 저장 경합 문제가 다시 나타날 수 있습니다. 배치 상태를 이해하지 못하는 0.1.11 이하로 되돌릴 때는 원격 배치를 모두 처리하거나 장면 분석을 끈 상태로 복원하여 중복 호출을 방지하세요.
- 릴리즈 공개는 운영 서버의 파일 교체나 재시작을 자동 수행하지 않습니다.
