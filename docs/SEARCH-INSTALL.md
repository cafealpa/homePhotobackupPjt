# 사진·얼굴 검색 설치

검색은 JVM 서버에 통합되었다. 기존 Python 설치 스크립트와 별도 검색 서비스는 제거했다.
[모델 준비·기존 설치 전환·설정 방법](JVM-VECTOR-SEARCH.md)을 따른다.

설정 화면의 **사진·얼굴 벡터 검색**에서 사진 모델과 장면·문서 모델의
**모델 확인·다운로드** 버튼을 누른다. 서버가 실제 사용하는 절대경로와 누락 파일이 표시된다.
이미 복사한 파일은 고정 SHA-256이 일치하면 다시 받지 않는다. 내려받은 파일은 임시 파일에서
체크섬을 검증한 뒤 교체하며, 네트워크·검증 실패 시 기존 파일을 보존한다.
진행 중에는 두 모델의 중복 다운로드를 막고, 화면을 닫아도 서버에서 계속 준비한다.
사진 모델은 약 1.5GB, 장면·문서 모델은 약 129MiB이며 서버에서 Hugging Face에 접속할 수 있어야 한다.
모델 폴더의 쓰기 권한과 다운로드용 여유 공간이 필요하다.

사진·얼굴 벡터 검색 사용을 켜고 설정을 저장하면 사진 인덱싱이 자동 실행된다.
모델 준비 후 사진은 최대 5분, 장면은 약 60초 뒤 재확인하며 재시작은 필요 없다.
중지한 작업은 프로세스 모니터 또는 사진 인덱싱 시작 버튼으로 재개한다.
기존 `prepare-search-model.ps1 -ModelDir ./models/siglip2`와
`prepare-caption-model.ps1 -ModelDir ./models/caption-e5`도 계속 사용할 수 있다.
운영 설정과 이전 LanceDB는 자동 변경하거나 삭제하지 않는다.
